# Security policy

## Reporting a vulnerability

Please report a vulnerability **privately**, through GitHub's private
vulnerability reporting: open the repository's **Security** tab and choose
**Report a vulnerability**
(<https://github.com/owlgraph-dev/owlgraph/security/advisories/new>). Please do
not open a public issue, pull request or discussion for it.

A useful report says:

- what an attacker can do, and what they need first (an account and its
  role, a share link, an API token, nothing at all);
- the steps to reproduce it, against a fresh install if you can
  (README.md, "Getting started");
- the version or commit you tested (the About page names both: `/-/about`,
  behind the info icon at the end of the footer).

You will get an answer within a week. Once a fix is released, the advisory is
published with credit to you, unless you would rather not be named.
